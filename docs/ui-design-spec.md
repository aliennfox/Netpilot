# Pilotty iOS UI/UX 设计规范

> 暗色主题，Surge 风格 Dashboard + 可切换 AI 对话界面。信息密度优先，专业工具感。

---

## 1. 设计理念

Pilotty 的界面兼具两种身份：
- **专业代理工具**：像 Surge 一样，用卡片化 Dashboard 展示网络状态、节点、规则、流量
- **AI 助手**：像 ChatGPT 一样，用对话界面让用户自然语言控制一切

用户可以在 Dashboard 模式和 Chat 模式之间一键切换。Dashboard 适合日常监控和快捷操作，Chat 适合复杂编排和故障排查。

## 2. 配色方案（暗色主题）

### 基础色

| Token | 色值 | 用途 |
|-------|------|------|
| `background.primary` | `#0A0A0F` | 主背景（纯黑偏蓝） |
| `background.secondary` | `#12121A` | 卡片/区块背景 |
| `background.tertiary` | `#1A1A26` | 输入框/列表行背景 |
| `background.elevated` | `#22222E` | 弹窗/浮层背景 |

### 文字色

| Token | 色值 | 用途 |
|-------|------|------|
| `text.primary` | `#EAEAF0` | 主要文字 |
| `text.secondary` | `#8888A0` | 次要/描述文字 |
| `text.tertiary` | `#55556A` | 禁用/极弱文字 |
| `text.inverse` | `#0A0A0F` | 深色背景上的反色文字 |

### 功能色

| Token | 色值 | 用途 |
|-------|------|------|
| `accent.blue` | `#4A9EFF` | 主强调色（连接中、活跃状态） |
| `accent.green` | `#34D399` | 成功/健康/已连接 |
| `accent.red` | `#F87171` | 错误/断开/危险 |
| `accent.orange` | `#FB923C` | 警告/延迟偏高 |
| `accent.purple` | `#A78BFA` | AI Agent 标识色 |
| `accent.teal` | `#2DD4BF` | 信息/提示 |

### 延迟色阶

| 延迟范围 | 色值 | 含义 |
|---------|------|------|
| 0-100ms | `accent.green` #34D399 | 极佳 |
| 100-300ms | `accent.teal` #2DD4BF | 良好 |
| 300-500ms | `accent.orange` #FB923C | 一般 |
| 500ms+ | `accent.red` #F87171 | 差 |
| 超时 | `text.tertiary` #55556A | 不可用 |

### 协议标识色

| 协议 | 色值 | 标签背景 |
|------|------|---------|
| Hysteria2 | `#4A9EFF` | 蓝色 |
| VLESS | `#A78BFA` | 紫色 |
| Shadowsocks | `#34D399` | 绿色 |
| Trojan | `#FB923C` | 橙色 |
| VMess | `#F87171` | 红色 |
| Direct | `text.secondary` | 灰色 |

#### 卡片说明

**连接状态卡片（最顶部，最重要）**
- 左上角圆点：绿色=已连接，红色=断开，橙色=连接中
- 当前节点名 + 协议标签 + 实时延迟
- 上传/下载累计流量 + 连接时长
- 底部一个主操作按钮（连接/断开）

**代理模式卡片**
- 三选一 Radio：直连 / 全局代理 / 规则模式
- 参考 Surge 的 Outbound Mode 卡片
- 底部两个快捷入口按钮

**实时流量卡片**
- 活跃连接数、TCP/UDP 分类
- 实时上传/下载速率

**订阅信息卡片**
- 订阅名称、节点数、到期日、剩余流量
- 更新按钮

**AI 快捷操作卡片**
- Pill 形状的快捷按钮，点击直接发送对应指令给 Agent
- 这是 Surge 没有的，Pilotty 独有

## 7. 组件规范

### 7.1 状态卡片 (StatusCard)

```
背景: background.secondary
圆角: 16pt
内边距: 16pt
阴影: 无（暗色主题不用阴影，用边界色区分层级）
边框: 无（用背景色差区分）
```

### 7.2 节点行 (NodeRow)

```
高度: 52pt
背景: background.secondary
左侧: 活跃指示器（蓝色圆点，6pt，仅当前节点显示）
中间: 节点名（text.primary） + 协议标签（小 pill，对应协议色）
右侧: 延迟数值（SF Mono，延迟色阶着色） + 状态图标
分割线: 0.5pt, text.tertiary，左缩进 16pt
```

### 7.3 协议标签 (ProtocolBadge)

```
形状: 圆角矩形 pill
圆角: 4pt
内边距: 水平 6pt, 垂直 2pt
字体: SF Pro Text 11pt Medium
背景: 协议对应色，20% 透明度
文字: 协议对应色，100% 不透明
```

### 7.4 快捷操作按钮 (QuickActionPill)

```
形状: 圆角胶囊
圆角: 16pt
内边距: 水平 14pt, 垂直 8pt
背景: background.tertiary
文字: text.primary, 13pt
点击态: accent.blue 背景，白色文字
```

### 7.5 Chat 气泡 (ChatBubble)

```
用户消息:
  对齐: 右
  背景: accent.blue
  文字: 白色, 15pt
  圆角: 16pt（左上、右上、左下 16pt，右下 4pt）
  最大宽度: 屏幕 75%

Agent 消息:
  对齐: 左
  背景: background.tertiary
  文字: text.primary, 15pt
  圆角: 16pt（左上、右上、右下 16pt，左下 4pt）
  最大宽度: 屏幕 85%
  
Agent 操作按钮:
  内嵌在气泡底部
  样式: 同 QuickActionPill
```

### 7.6 连接/断开主按钮

```
连接状态:
  形状: 圆角矩形，宽度 100%
  高度: 44pt
  背景: accent.green
  文字: "断开连接", 白色, 16pt Semibold

断开状态:
  背景: accent.blue
  文字: "连接", 白色

  背景: accent.orange
```

## 8. 动画与交互

| 交互 | 动画 |
|------|------|
| Dashboard ↔ Chat 切换 | 水平滑动过渡，0.3s ease |
| 卡片加载 | 从下往上淡入，0.2s，依次延迟 0.05s |
| 节点切换 | 旧节点行淡出蓝点 → 新节点行淡入蓝点，0.2s |
| 延迟测速 | 数值位置显示旋转动画 → 结果淡入 |
| Chat 消息 | 新消息从底部滑入，0.2s |
| Agent 思考中 | 三个点跳动动画（ChatGPT 风格） |
| 连接/断开 | 按钮颜色渐变过渡，0.3s |

## 9. 暗色主题注意事项

- 不使用纯黑 `#000000`，使用偏蓝的深色 `#0A0A0F` 作为主背景
- 不使用阴影来区分层级，改用背景色差（primary → secondary → tertiary）
- 文字不使用纯白 `#FFFFFF`，使用偏暖的 `#EAEAF0` 减少刺眼感
- 所有彩色元素降低饱和度 10-15%，避免在暗背景上过于刺眼
- 分割线使用 `text.tertiary` 0.5pt，低存在感
- 状态栏使用 `.preferredColorScheme(.dark)`

## 10. 适配要求

- 最低支持 iOS 17.0
- 适配 iPhone SE 3 (4.7") 到 iPhone 16 Pro Max (6.9")
- Safe Area 正确处理（刘海/灵动岛）
- 键盘弹出时 Chat 输入框正确上移
- 支持 Dynamic Type（辅助功能字体缩放）
- 横屏不支持（锁定竖屏）
